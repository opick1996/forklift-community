# Contributing to FORKLIFT

Thanks for helping improve FORKLIFT.

## Ways to contribute

- Improve documentation and explanations.
- Share useful Web3 learning resources.
- Suggest beginner-friendly project ideas.
- Report broken links or unclear instructions.
- Review pull requests with constructive feedback.

## Pull request checklist

1. Keep each change focused.
2. Explain what changed and why.
3. Link a related issue when possible.
4. Never include private keys, seed phrases, passwords, or personal data.
5. Avoid unsupported claims, guaranteed returns, or misleading token information.

## Issues

Use a clear title and provide enough context for others to understand your suggestion.
