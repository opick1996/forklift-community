# FORKLIFT

![FORKLIFT coin logo](assets/forklift-coin-logo.png)

![FORKLIFT — community project](assets/forklift-hero.png)

**A community-powered open-source project for Web3 builders.**

FORKLIFT is a lightweight community hub for sharing ideas, learning resources, and experiments across the open-source ecosystem.

## What we're building

- A welcoming place for Web3 builders and curious contributors.
- A collection of practical learning resources.
- Open discussions around useful tools and experiments.
- A transparent record of community ideas and contributions.

## Get started

1. Read [Community Principles](docs/COMMUNITY.md).
2. Explore the [Roadmap](ROADMAP.md).
3. Review [Contributing](CONTRIBUTING.md).
4. Open an issue to suggest an idea or improvement.

## Repository structure

- `docs/COMMUNITY.md` — values and participation guidelines.
- `ROADMAP.md` — project priorities and ideas.
- `CONTRIBUTING.md` — how to contribute.
- `LICENSE` — MIT License.
